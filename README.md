# RedirectResolver
Browser extension that intercepts short-links (t.co, bit.ly, and more) and resolves them to their final destination.

<img width="630" height="481" alt="screenshot" src="https://github.com/user-attachments/assets/7c92add1-b2a9-4722-b3b6-40ba5671e1ae" />

## Goals
The main objectives are (in no particular order):
* Being able to navigate to webpages behind short-link services blocked by some DNS lists
* Protect user privacy by resolving the redirects before the browser automatically sends tracking data through them
* Follow all redirects in the background, preventing the browser itself from visiting each intermediate page
* Strip tracking parameters from the final url
* Give the user visibility and control over the page they are about to visit after all redirects

## Download

Available as a Firefox extension for Firefox for Desktop and Firefox for Mobile.
